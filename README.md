# World Changers · 世界改变者图鉴

An atlas of the archetypes behind every great system — sixteen paths that changed the world, from the Yellow Emperor to the nameless. Not a hall of fame: a field guide to the patterns of builders. Systems and ideas outlive conquest and power.

一部改变者原型的图谱——十六种改变世界的路径，从黄帝到无名者。不是名人堂，而是建设者的模式指南：思想与制度，比征服与权力长寿。

- Next.js 14 (App Router, `src/app`)
- Plain CSS design system (Fraunces / Space Grotesk / Noto Serif SC / JetBrains Mono)
- Static generation: 16 detail pages + home

## Features

- 16 changers, each with: origin, core weapon, key moves, legacy, tech analog, takeaway — bilingual EN/ZH
- Archetype filter on the atlas grid
- The Seven-Segment Roadmap: Nurhaci → Liu Bang → Genghis Khan → Duke Wen of Jin → Yuwen Tai → King Wen → Huangdi
- Full SEO/GEO metadata, OG card, Psyverse analytics tracker
